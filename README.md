## Full UI Redesign: CyberCoffee

Completely redesign and refactor the current CyberCoffee website UI. **Do not preserve the existing visual decisions just because they already exist. Be ruthless.** The current design looks like generic AI-generated cyberpunk slop: excessive gradients, weak typography hierarchy, decorative noise, oversized empty areas, inconsistent visual weight, and too many effects competing for attention.

### Core direction

Create a **premium cyberpunk specialty coffee brand**, not a sci-fi dashboard.

Think:

* underground coffee lab
* hacker café
* Japanese/Korean cyber-industrial graphic design
* premium specialty coffee branding
* dark editorial website
* restrained neon accents

The design should feel **intentional, expensive, sharp, and usable**.

### 1. Completely fix typography

* Replace the current difficult-to-read display typography wherever it hurts readability.
* Use **one strong display font + one highly readable UI/body font**.
* Never use futuristic fonts for paragraphs, descriptions, prices, or navigation if they reduce readability.
* Establish a strict hierarchy:

  * huge display heading
  * medium section heading
  * readable body text
  * compact labels
  * clear prices
* Increase contrast dramatically.
* Stop using thin gray text on dark backgrounds.
* Body text should be comfortably readable without zooming.
* Navigation text must be immediately legible.
* Prices must visually stand out from descriptions.
* Avoid ALL-CAPS unless it genuinely improves the UI.
* Fix letter spacing. Do not over-track normal text.

### 2. Destroy the excessive cyberpunk effects

Remove or heavily reduce:

* scanlines covering everything
* excessive glow
* noisy gradients
* giant transparent circles
* random floating dots
* unnecessary neon borders
* decorative lines that don't communicate anything
* excessive purple/pink overlays
* fake HUD/dashboard elements

Cyberpunk should come from **color, typography, geometry, imagery, and spacing**, not from putting a glow on every pixel.

Use effects sparingly.

### 3. Establish a real color system

Use a restrained palette:

* Background: near-black / charcoal
* Surface: slightly lighter charcoal
* Primary text: warm off-white
* Secondary text: muted cool gray
* Accent 1: electric violet
* Accent 2: hot magenta/pink
* Optional accent: cyan used very sparingly

Do NOT make the entire website purple.

Neon colors should function as accents and interaction states, not as the foundation of every component.

### 4. Completely redesign the hero

The current hero is oversized and visually empty.

Create a much tighter composition:

* strong headline
* concise supporting copy
* two clear CTAs
* high-quality coffee visual/product photography
* subtle technical/cyber details around the imagery
* significantly better vertical balance

Make the coffee the hero, not a random glowing circle containing a generic cup icon.

The hero should communicate **“this is a real premium coffee shop with a cyber identity”** within 3 seconds.

### 5. Redesign the navigation

Make the navbar:

* compact
* clean
* properly aligned
* visually stable
* readable

Keep the logo treatment but simplify it.

The ORDER button should look like a real premium CTA, not a glowing game UI button.

Add proper hover/focus/active states.

### 6. Completely rebuild the menu cards

The current menu cards feel like AI-generated product tiles.

Create a proper premium coffee menu system:

* larger, cleaner product imagery
* consistent image aspect ratio
* consistent card heights
* obvious product name
* category
* price
* concise description
* simple add-to-cart interaction

Remove unnecessary giant empty spaces.

Use **real visual hierarchy instead of borders and gradients**.

The product image should be the visual focus.

Make cards feel like something from a high-end coffee brand, with the cyber aesthetic layered on top.

### 7. Fix the imagery

The coffee images currently look pasted onto generic backgrounds.

Give product imagery:

* consistent framing
* consistent lighting
* consistent scale
* clean backgrounds
* realistic presentation
* subtle brand treatment

Do not use random decorative fruit/coffee beans everywhere unless they are actually part of the product photography.

### 8. Redesign the “Infrastructure” section

The current “CORE INFRASTRUCTURE / BEAN PROTOCOL / MATCHA MATRIX” section feels like an AI invented a tech vocabulary generator.

Make the content actually useful.

Rename sections using normal premium-brand language while keeping subtle cyber terminology.

Example direction:

* Our Beans
* Matcha Lab
* Brewing Process
* Network / Locations
* Rewards

Keep the technical aesthetic through layout and visual language, **not cringe terminology**.

### 9. Improve spacing and layout

Use a consistent responsive grid.

Stop:

* enormous empty hero regions
* arbitrary card dimensions
* excessive vertical padding
* awkward alignment
* elements floating without a clear grid

Use generous whitespace, but make it intentional.

Desktop should feel editorial and premium.

Mobile should be completely redesigned responsively rather than simply stacking desktop elements.

### 10. Make interactions feel premium

Add subtle:

* hover transitions
* image zoom
* button feedback
* card elevation/lighting changes
* active navigation states
* smooth page transitions

Animations should be **fast, subtle, and purposeful**.

No constant floating animations.
No seizure-inducing neon.
No excessive parallax.

### 11. Fix accessibility

Prioritize:

* WCAG-friendly contrast
* readable font sizes
* keyboard navigation
* visible focus states
* semantic HTML
* accessible buttons
* accessible images/alt text
* reduced-motion support

Aesthetic should never override usability.

### 12. Content cleanup

Rewrite awkward AI-sounding copy.

Avoid phrases like:

* “compiled executable of flavor”
* “ceremonial-grade cyber-monks”
* “caffeine IV drip”
* fake technical jargon that adds no meaning

Keep the personality, but make it sound like an actual brand created by humans.

The tone should be:

**underground + technical + confident + slightly rebellious + genuinely obsessed with coffee**

Not:

**“ChatGPT was asked to make a cyberpunk café in 2026.”**

### Final requirement

Treat the existing implementation as a **rough prototype, not a design to preserve**.

Refactor the entire visual system:

* typography
* colors
* spacing
* layout
* components
* cards
* navigation
* hero
* imagery
* copy
* buttons
* responsive behavior
* animations
* accessibility

Preserve the site's actual functionality and content/data structure where practical, but **do not preserve bad UI decisions**.

The final result should look like a real premium cyberpunk coffee brand website, not an AI-generated dashboard wearing a coffee costume.

**If something looks cool but hurts readability, remove it.
If something looks futuristic but feels generic, remove it.
If something exists only because “cyberpunk websites usually have it,” remove it.**

Prioritize **brand, hierarchy, readability, composition, and usability first.**
